# Customer Shopping Behavior Analysis

## Project Overview

This project focuses on analyzing customer shopping behavior using Python, SQL, and Power BI. The objective is to clean and analyze customer data, extract meaningful insights using SQL queries, and create an interactive dashboard for better business decision-making.

---

## Dataset

The dataset contains customer shopping information, including purchase details and customer attributes. It is used to identify shopping trends, customer behavior, and purchasing patterns.

---

## Tools & Technologies

- Python
- Pandas
- NumPy
- PostgreSQL
- SQL
- Power BI
- Jupyter Notebook

---

## Project Workflow

### 1. Data Loading
- Loaded the dataset into Python using Pandas.
- Imported the data into PostgreSQL for SQL analysis.

### 2. Data Cleaning
- Checked for missing values.
- Removed duplicate records.
- Corrected data types.
- Prepared the dataset for analysis.

### 3. Exploratory Data Analysis (EDA)
- Analyzed customer demographics.
- Examined purchasing behavior.
- Generated descriptive statistics.
- Identified important trends and patterns.

### 4. SQL Analysis
Executed SQL queries to:
- Retrieve customer information.
- Filter and sort records.
- Perform aggregations.
- Group customer data.
- Generate business insights.

### 5. Dashboard Creation
Created an interactive Power BI dashboard to visualize:
- Customer distribution
- Purchase trends
- Sales insights
- Category analysis
- Business KPIs

4. Load the dataset.

5. Execute the notebook cells.

6. Import the SQL script into PostgreSQL if required.

7. Open the Power BI dashboard to explore the visualizations.
